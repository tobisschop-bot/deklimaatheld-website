# De Klimaatheld – website

Astro-site, gehost op Netlify.

- `npm install` → `npm run dev` (lokaal op http://localhost:4321)
- `npm run build` → statische site in `dist/`

## Structuur
- `src/styles/global.css` – huisstijl (kleuren, typografie, kaarten)
- `src/data/site.ts` – bedrijfsgegevens (placeholders invullen)
- `src/data/warmtepompen.ts` – Weheat-modellen + indicatieve prijzen
- `src/components/` – Header, Footer, Logo, Button
- `src/pages/` – pagina's (bestandsnaam = URL)
